## 技术实现要点

### 1. 时长控制
通过共享权重机制实现：
```python
# 位置编码和时长编码使用同一个Embedding
W_sem ≡ W_num
duration_embed = position_embedding(target_length)
```

### 2. 梯度反转层
自定义Autograd函数：
```python
class GradientReversalFunction(Function):
    @staticmethod
    def forward(ctx, x, lambda_):
        return x  # 恒等映射
    
    @staticmethod
    def backward(ctx, grad_output):
        return -lambda_ * grad_output, None  # 梯度反转
```

### 3. 条件流匹配
直接回归速度向量：
```python
x_t = (1-t) * x_0 + t * x_1  # 插值
v_target = x_1 - x_0          # 目标速度
loss = MSE(v_pred, v_target)  # CFM Loss
```

### 4. GPT融合
长度对齐 + 特征融合：
```python
# 1. 上采样T2S隐藏状态到Mel长度
gpt_aligned = interpolate(gpt_hidden, target_len)

# 2. 融合语义特征和GPT特征
fused = MLP(concat(semantic_features, gpt_aligned))
```
